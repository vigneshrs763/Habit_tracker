# 🌱 HabitPulse

HabitPulse is a modern and responsive habit-tracking web application built using HTML, CSS, and JavaScript. It helps users track daily habits, maintain streaks, monitor progress, and stay motivated.

## ✨ Features

- ✅ Add, complete, and delete habits
- 🔥 Track current and best streaks
- 📊 View daily and weekly progress
- 💬 Built-in motivational commands
- 🌙 Light and dark mode
- 💾 Data persistence using LocalStorage
- 📱 Responsive design for desktop and mobile

## 💬 Commands

HabitPulse includes simple commands for quick feedback:

- `/motivate` — Get motivational feedback
- `/streak` — View your current and best streak
- `/stats` — View habit statistics
- `/today` — Check today's remaining habits
- `/quote` — Get a motivational quote
- `/restart` — Get a fresh-start message

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- LocalStorage
